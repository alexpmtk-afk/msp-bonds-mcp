[05 | MCP]
Проектируем read-only инструменты мониторинга и аналитики российских корпоративных облигаций; конкретные tools и API утвердить после проверки источников.
Каждый результат расчёта: источник, дата/время среза, идентификатор бумаги (ISIN при наличии), единицы, метод, актуальность данных.
Пропуски/ошибки API не заменять догадками. Сырые данные отличать от расчётных значений.
Права чтения и потенциальной записи разделять. Торговые операции по умолчанию отсутствуют.
ТЕХНИЧЕСКИЙ GOOGLE-КОННЕКТОР: модульный исходный код v0.3.0; Python 3.13.1/MCP SDK 2.3.0; 17/17 тестов пройдены; stdio подтвердил прежние 16 имён и схем инструментов. OAuth не настроен; google_oauth_status подтвердил отсутствие токенов, живой Google API не вызывался. Метаданные пакета в .venv остаются 0.2.1: штатное обновление без сетевых загрузок остановилось из-за отсутствующего setuptools. Это технический Drive/Gmail-коннектор, не аналитический и не торговый сервер облигаций.
