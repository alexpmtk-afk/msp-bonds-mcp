[05 | MCP]
Проектируем read-only инструменты мониторинга и аналитики российских корпоративных облигаций; конкретные tools и API утвердить после проверки источников.
Каждый результат расчёта: источник, дата/время среза, идентификатор бумаги (ISIN при наличии), единицы, метод, актуальность данных.
Пропуски/ошибки API не заменять догадками. Сырые данные отличать от расчётных значений.
Права чтения и потенциальной записи разделять. Торговые операции по умолчанию отсутствуют.
