Создать MCP-сервер на HOME для организации доказательного исследования и сопровождения данных о российских корпоративных облигациях совместно с ChatGPT.
ТОЛЬКО: российские корпоративные выпуски/эмитенты. ОФЗ, иностранные облигации, акции пока исключены.
ФУНКЦИИ: учёт позиций; доходность и выплаты; оценка эмитентов/выпусков; проверка рисков; поиск подходящих выпусков; сигналы ухудшения; обоснованные рекомендации по продаже, докупке и ребалансировке.
ПРИНЦИП: надёжность и проверяемая выгода важнее максимального купона.
НЕТ: автоматической торговли без отдельного явного согласования. Действующая политика определяется авторизованной закрытой методикой, не публичным кодом.

ЦЕЛЕВАЯ СХЕМА (24.11.2026, согласована; реализация и приёмка впереди): MCP выполняет массовый предварительный поиск по действующей закрытой методике, формирует карту применимых проверок и источников, предоставляет точечные read-only данные по запросу. ChatGPT изучает доказательства, оценивает их и формирует заключение. Не загружать все документы всех источников для каждого кандидата заранее. Повторно использовать только актуальные проверенные факты юридически идентифицированного эмитента; условия каждого выпуска проверять отдельно. Сохранять структурированные доказательства, даты, ссылки, статус и причину остановки вместо массового архива сырья. Отсутствие сведений — неопределённость, не подтверждённый риск. Подтверждённое несоответствие обязательному правилу позволяет завершить проверку с указанием непроверенных пунктов.
