[10 | GMAIL → DRIVE: ИМПОРТ ВТБ | 21.11.2026]
ЦЕЛЬ: поэтапно перенести ручной процесс Gmail → Drive в один локальный MCP. Gmail OAuth для локальной среды HOME подтверждён владельцем только в рамках профильной read-only проверки; поиск писем ВТБ, чтение вложений и импорт остаются отдельными непроверенными этапами. Подключение Drive к механизму импорта ВТБ не подтверждено.

ТРЕБОВАНИЯ К БУДУЩЕМУ ИМПОРТУ:
1. Искать письма только на чтение; тип документа определять по содержимому вложения, не только по теме, имени или MIME. Уведомления о корпоративных действиях держать отдельно.
2. Поддерживать произвольное число счетов. При неясном типе или реквизитах требовать ручной проверки.
3. Получать оригинальные байты вложения через Gmail API или raw MIME, проверять PDF/XLSX по содержимому и считать SHA-256.
4. Сверять с существующим архивом и метаданным журналом. Точный дубль, возможную другую версию и пересечение периода различать; пересечение само по себе не является дублем.
5. Запись в Drive включать отдельно, только с обратным чтением и совпадающим SHA-256. Не перезаписывать и не удалять оригиналы автоматически.

GMAIL OAUTH — HOME, 21.11.2026:
Владелец сообщил, что в обычной среде HOME сохранённая Gmail-авторизация загрузилась, однократный users.getProfile завершился PASS с кодом 0, Gmail API включён, разрешение — gmail.readonly. Повторный живой запрос в рамках этой задачи не выполнялся. Проверка исходного кода подтвердила обновление истёкшего access token по refresh token с сохранением обновлённой записи в Windows Credential Manager.
Эта профильная проверка не доказывает, что поиск писем ВТБ или получение вложений уже выполнены. Письма и вложения в этой задаче не открывались; Drive, таблица и рабочий журнал не изменялись.

Реальная архивная выборка проверялась отдельно только для чтения; детали остаются в закрытых локальных материалах и Google Drive.

На тот момент Gmail, OAuth, живые Google API и запись в Drive не проверялись. Эта историческая запись заменена подтверждением только профильного запроса выше, не подтверждением поиска и импорта.
