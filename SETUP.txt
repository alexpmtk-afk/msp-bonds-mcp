Требуется Python 3.11 или новее. Проверенная среда использовала Python 3.13.1.

В Windows PowerShell из корня репозитория:

    py -3.13 -m venv .venv
    .\.venv\Scripts\python.exe -m pip install setuptools wheel
    .\scripts\install-local.ps1
    .\scripts\test-all.ps1

Для запуска сервера через стандартный ввод-вывод используйте .\scripts\start-local.ps1. Установка сценария выполняет три локальных пакета в .venv; зависимости объявлены в соответствующих pyproject.toml.

Примеры конфигурации находятся в .env.example и каталогах компонентов. Они не применяются автоматически. Не коммитьте настоящие учётные данные, токены, OAuth-файлы, отчёты брокера, сведения о портфеле или локальные конфигурации. Google-записи по умолчанию выключены; OAuth и живой доступ к API должны настраиваться отдельно.

Публичный репозиторий не подключает компьютер HOME как исполнитель CI-задач. Перед запросом на слияние проверяйте изменения, тестовые файлы и журнал безопасности.

## Gmail OAuth на HOME, только чтение

Для проверки наличия локальной записи запустите из корня проекта:

    .\.venv\Scripts\python.exe -B -m msp_bonds_google.cli status

Статус показывает наличие записи в Windows Credential Manager, но не подтверждает, что API принимает токен. Процедура первого входа владельца, автоматического обновления токена и безопасной проверки Gmail описана в components/google_workspace/docs/GMAIL_OAUTH_SETUP.md.

Первоначальный вход выполняет владелец в браузере командой python -B -m msp_bonds_google.cli login gmail после задания переменной MSP_GOOGLE_OAUTH_CLIENT на локальный Desktop OAuth JSON. Не загружайте этот файл в репозиторий и не передавайте его содержимое. Для Gmail запрашивается только gmail.readonly.

При обычном вызове Gmail MCP использует существующий механизм обновления access token через refresh token и сохранения обновлённой записи в Windows Credential Manager. Это обновление происходит по запросу, не в фоне. Одна проверка users.getProfile не читает писем или вложений и требует отдельного разрешения владельца. Не включайте gmail.modify для чтения.
