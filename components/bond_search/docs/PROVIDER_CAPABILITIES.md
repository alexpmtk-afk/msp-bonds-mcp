# Состояние загрузчиков официальных источников

Проверено 15 ноября 2026 года. Этот документ описывает только возможности компонента bond_search; он не содержит правил отбора конкретных бумаг, идентификаторов пользовательских таблиц или данных портфеля.

## Реализовано

### MOEX ISS — точная проверка ISIN

Компонент запрашивает поиск по ISIN. Если поисковый метод возвращает пустой ответ, прежде чем сообщить об отсутствии совпадения, компонент сверяет ISIN с текущим списком облигаций MOEX. Совпадение подтверждает только наличие такого идентификатора в ответе MOEX; оно не подтверждает качество эмитента, условия выпуска, рейтинг, купоны, платёжеспособность или пригодность для портфеля.

Для транспортного сбоя доступны коды этапа: DNS, TLS, соединение, HTTP-статус, чтение ответа и разбор JSON. Повтор ограничен двумя попытками на запрос и применяется только к временным сетевым сбоям и HTTP 500–504. Размер ответа ограничен. Неуспешный запрос и пустой ответ поиска не считаются подтверждением отсутствия бумаги.

[Документация MOEX ISS](https://www.moex.com/a2920) описывает общедоступные справочные данные и задержанные рыночные данные. [Условия использования сведений ISS](https://www.moex.com/a2193) ограничивают их ознакомительными целями; иное использование требует отдельного договора с Московской биржей.

## Пока только ручная проверка

| Проверка | Официальный источник | Текущее ограничение |
|---|---|---|
| Кредитный рейтинг и действия агентства | [Репозитарий Банка России](https://ratings.cbr.ru/) | Веб-поиск доступен; автоматический запрос через документированный открытый интерфейс пока не подтверждён. |
| Юридические условия купона и оферты | Решение о выпуске, официальный сайт эмитента, данные НРД | Рыночное поле или найденная дата выплаты не заменяют первичный документ выпуска. |
| Амортизация и погашение | [Страница MOEX по облигациям](https://www.moex.com/ru/bondization) и решение о выпуске | До программного разбора первичного источника график не считается проверенным. |
| Банкротство и дефолтные события | [Федресурс](https://fedresurs.ru/), [Картотека арбитражных дел](https://kad.arbitr.ru/) | Результат поиска должен быть проверен по официальной записи; неполный поиск не трактуется как отсутствие событий. |
| Финансовая отчётность эмитента | [Ресурс БФО ФНС](https://bo.nalog.gov.ru/) | Публичный веб-поиск доступен; REST API ФНС предоставляется по подписке. У компонента нет настроенного доступа к этому API. |

## Google Workspace

Чтение вкладок «логика поиска» и «ресурсы поиска» подключается к функции msp_bonds_google.workspace.sheets_read уже установленного компонента Google Workspace. Компонент поиска не хранит второй OAuth-токен, не запускает вход в Google и не пишет в таблицу. Если штатная запись доступа отсутствует в Windows Credential Manager, чтение завершится явным статусом EXISTING_DRIVE_CREDENTIAL_MISSING.

## Принцип обработки пробелов

Неизвестное значение остаётся неизвестным. Ошибка сети, пустой ответ, недоступный официальный интерфейс или отсутствие документа не преобразуются в ноль, отрицательный факт либо подтверждённое значение. Полная последовательная проверка и подключение к основному MCP не включены.
