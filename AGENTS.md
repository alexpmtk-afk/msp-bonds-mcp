# Стартовая точка для локального Codex

Прочитай целиком instructions/00_START.txt, затем 01_GOAL.txt, 02_ARCHITECTURE.txt, 04_CODEX.txt, 05_MCP.txt, 07_SECURITY.txt. Остальные TXT читай по теме текущей задачи. Подтверди, какие прочитаны; если нет доступа, сообщи об этом.

Не публикуй секреты, данные реального портфеля и приватные настройки. Не включай торговлю или доступ HOME без отдельного согласования.

Прежде чем работать, прочитай также корневые 00–03 TXT на Google Диске проекта, включая 03_АКТУАЛЬНОСТЬ_ПРОЕКТА.txt; после значимой подтверждённой задачи обновляй актуальный первоисточник и проверяй запись. Если Drive недоступен, сообщи об этом, не считай контекст прочитанным.

После каждой значимой подтверждённой задачи или утверждённого владельцем решения ВРУЧНУЮ актуализируй соответствующие файлы И в Google Drive, И в GitHub (с учётом PUBLIC/PRIVATE). Проверь обе записи чтением. Автоматической синхронизации нет; при недоступности одного хранилища сообщи о расхождении.

Для Gmail OAuth применяй .agents/skills/google-gmail-oauth/SKILL.md и components/google_workspace/docs/GMAIL_OAUTH_SETUP.md. Они описывают существующий механизм, безопасные команды и границу между проверкой статуса, живой проверкой профиля и обнаружением инструментов. Живые операции выполняй только с прямым разрешением владельца.
