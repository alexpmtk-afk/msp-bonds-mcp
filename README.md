# MSP Bonds MCP (PUBLIC)

Проект MCP-сервера для анализа портфеля российских корпоративных облигаций на компьютере HOME. Аналитический сервер облигаций и торговые функции пока не реализованы.

**В GitHub нет реальных данных портфеля, паролей, токенов и индивидуальных конфигураций HOME.**

Старт для ChatGPT и разработчиков: instructions/00_START.txt.
Старт для локального Codex: AGENTS.md и короткие TXT.
Приватная политика и закрытая настройка HOME ведутся в msp-bonds-private. Секреты не коммитить даже туда.

## Проверенный локальный компонент

На HOME 15.11.2026 проверена одна stdio точка запуска: корневой пакет msp-bonds-mcp 0.4.0, Google Workspace component 0.3.1 и VTB reports component 0.1.0. Установленные версии совпадают с проектными метаданными. Все 46 локальных тестов прошли; stdio сохранил прежние 16 инструментов и схемы.

В локальном компоненте ВТБ подготовлены офлайн-классификатор и метаданный журнал повторов; XLSX-текст читается из синтетических тестовых файлов. PDF-разбор пока недоступен. Эти возможности проверены только на синтетических данных и пока не опубликованы в исходниках репозитория.

OAuth, живой доступ к Google API, реальные документы и облачные операции не проверялись и не выполнялись.

## Состояние исходников GitHub

Этот публичный репозиторий пока не содержит исполняемого Python-комплекта: в src/ и tests/ размещены только поясняющие файлы, а корневой pyproject.toml отсутствует. Локальная версия 0.4.0 ещё не перенесена в этот репозиторий; инструкции описывают подтверждённое состояние HOME, а не готовый к установке GitHub-комплект. Синхронизацию исходников нужно выполнить отдельно.

Общее хранилище проектных инструкций и документов — выделенная папка Google Drive. Точный путь и доступ к ней проверять перед автоматизацией.
