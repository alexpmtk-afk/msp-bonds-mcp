# MSP Bonds MCP (PUBLIC)

Локальный stdio MCP-сервер для технических операций Google Workspace и проверки архива отчётов. Аналитические рекомендации по облигациям и торговые операции пока не реализованы.

**В GitHub не хранятся реальные данные портфеля, пароли, токены и индивидуальные настройки HOME.**

Старт проекта: `instructions/00_START.txt`; для Codex также `AGENTS.md`. Закрытая проектная политика хранится отдельно; секреты нельзя коммитить ни в открытый, ни в закрытый репозиторий.

## Состояние исходников в GitHub

Текущий `main` (`bcf9466`) ещё не содержит исполняемых Python-исходников. Открытый PR №1 (`c4d289a`) добавляет их отдельной веткой; он ещё не слит. Подготовленная локальная копия сохраняет исходники этого PR и объединяет их с актуальными инструкциями `main`.

В PR №1 доступны:

- `msp-bonds-mcp` 0.4.0 — общий сервер и ядро.
- `msp-bonds-google-workspace` 0.3.1 — операции Google Workspace с локальным подтверждением записей.
- `msp-bonds-vtb-reports` 0.1.0 — только перечень файлов архива и проверка признаков формата PDF/XLSX. Этот опубликованный код не извлекает текст отчётов, не классифицирует их и не ведёт журнал импорта.

Компоненты работают через одну stdio-точку запуска. Подготовленный кандидат прошёл 25 офлайн-тестов и отдельную stdio-проверку: 16 прежних MCP-инструментов и их схемы совпали. Начните с `instructions/00_START.txt`; команды настройки и тестирования находятся в `SETUP.txt`.

## Более свежая реализация ВТБ на HOME

Отдельная локальная версия ВТБ включает офлайн-извлечение текста XLSX, классификацию трёх типов документов, маршрутизацию ярлыков и SQLite-журнал повторов. PDF-разбор пока недоступен. Эти возможности не входят в исходный код PR №1 и не должны считаться опубликованными в GitHub.

На HOME этап 2 завершён: 28 тестов компонента ВТБ и 48 тестов проекта прошли, включая контракт 16 инструментов. Рабочий локальный журнал создан с пустой схемой и 0 записями. Сейчас в отдельной задаче проверяют классификатор на оригинальных документах; эта проверка ещё не завершена. Её изменения и результаты не входят в PR №1.

Офлайн-тесты используют синтетические файлы и не доказывают точность на оригиналах. Gmail, OAuth и живой Google API не подключались.

## Безопасность

Публичный репозиторий не содержит секретов, реальных финансовых документов, личных настроек или путей HOME. Файлы `.env.example` — только пустые или условные шаблоны; они автоматически не загружаются.
