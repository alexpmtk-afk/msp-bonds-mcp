# MSP Bonds MCP (PUBLIC)

Проект локального MCP-сервера для анализа портфеля российских корпоративных облигаций на HOME. Аналитический сервер облигаций и торговые функции пока не реализованы.

**В GitHub нет реальных данных портфеля, брокерских документов, паролей, токенов и индивидуальных конфигураций HOME.**

Старт для ChatGPT и разработчиков: instructions/00_START.txt. Старт для локального Codex: AGENTS.md и короткие TXT. Приватная политика и закрытая настройка HOME ведутся в msp-bonds-private. Секреты не публиковать даже в PRIVATE.

## Проверенный локальный компонент

На HOME проверена одна stdio-точка запуска: корневой пакет msp-bonds-mcp 0.4.0, Google Workspace 0.3.1 и VTB reports 0.1.0. Метаданные пакетов совпадают с исходниками. На 15.11.2026 пройдены 56/56 локальных тестов; stdio сохранил прежние 16 инструментов и их входные схемы.

Локальный компонент ВТБ читает XLSX и PDF, классифицирует документы по содержимому и ведёт только метаданные сверки/импорта. PDF извлекаются локально через pypdf; OCR и облачные вызовы для разбора не используются. Архивная выборка проверялась закрыто и только на чтение; документы, реквизиты и результаты по отдельным файлам в репозиторий не добавлялись.

OAuth, живой доступ к Gmail/Google API и облачные операции записи не проверялись и не выполнялись. Поддержка сканированных PDF без текстового слоя не подтверждена.

## Состояние исходников GitHub

Этот публичный репозиторий пока не содержит исполняемого Python-комплекта: в src/ и tests/ размещены поясняющие файлы, корневой pyproject.toml отсутствует. Локальные исходники компонентов не опубликованы; README описывает проверенное состояние HOME, а не готовый пакет для установки. Синхронизацию исходников следует выполнять отдельно.

Общее хранилище проектных инструкций и документов — выделенная папка Google Drive. Точный путь и доступ проверять перед автоматизацией.
