# MSP Bonds MCP (PUBLIC)

Локальный stdio MCP-сервер для технических операций Google Workspace и проверки архива отчётов. Аналитические рекомендации по облигациям и торговые операции не реализованы.

**В открытом GitHub не публикуются реальные данные портфеля и брокерских документов, секреты, персональные данные или личные настройки HOME.**

Старт проекта: `instructions/00_START.txt`; правила изменения исходников: `instructions/08_CHANGE_CONTROL.txt` и `instructions/11_CHAT_COORDINATION.txt`. Закрытая проектная политика хранится отдельно.

## Историческая запись о HOME

Последняя сохранённая локальная проверка датирована 15.11.2026: корневой пакет
0.4.0, Google Workspace 0.3.1, VTB reports 0.1.0; 56/56 локальных тестов и
16 MCP-инструментов. Это историческая запись, а не независимое подтверждение
текущей установки. В этом обновлении HOME не проверялся и тесты не запускались.
Публичный GitHub не подтверждает текущие версии, список инструментов или OAuth
на локальном компьютере.

## Состав публичного кода

Основной публичный коммит `846b762753ab01573f51ea8a71b62ac39ffb305f`
от 16.11.2026 содержит общий MCP-код и компоненты Google Workspace и VTB
reports. PR №1 с техническими исходниками объединён.

PR №5 добавил в `main` отдельный компонент Telegram и инструмент
`send_telegram_notification`. На публичной ветке это 17 инструментов:
прежние 16 и отдельный инструмент Telegram. Наличие исходников не подтверждает
настройку локального токена или реальную доставку уведомления.

В `main` также есть базовый компонент `bond_search` 0.1.0 для чтения
переданного снимка правил и ограниченного поиска кандидатов. Полная оценка
рисков и торговые операции не реализованы. PR №4 с улучшенной проверкой MOEX,
доказательств и статуса Workspace остаётся открытым черновиком и в `main` не
влит. Установка его точного коммита в чистое окружение не подтверждена.

Компоненты используют общее ядро и одну stdio-точку запуска. Отдельный сервер
bond_search и автономные торговые функции не создавались.

## Настройка и безопасность

Инструкции и команды настройки находятся в `instructions/` и `SETUP.txt`. Файлы `.env.example` — только шаблоны; они не загружаются автоматически.

Секреты, токены, личные конфигурации HOME, финансовые документы, резервные копии и временные данные не должны попадать в этот репозиторий.
