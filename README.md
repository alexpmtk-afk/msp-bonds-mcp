# MSP Bonds MCP (PUBLIC)

Локальный stdio MCP-сервер для технических операций Google Workspace и проверки архива отчётов. Аналитические рекомендации по облигациям и торговые операции не реализованы.

**В открытом GitHub не публикуются реальные данные портфеля и брокерских документов, секреты, персональные данные или личные настройки HOME.**

Старт проекта: instructions/00_START.txt; правила изменения исходников: instructions/08_CHANGE_CONTROL.txt и instructions/11_CHAT_COORDINATION.txt. Закрытая проектная политика хранится отдельно.

## Проверенное состояние Gmail OAuth и HOME

21.11.2026 владелец сообщил: сохранённые Gmail-учётные данные успешно загружаются в обычной среде HOME; однократный read-only запрос users.getProfile завершился PASS, использовалось разрешение gmail.readonly, Gmail API включён в Google Cloud.

Проверка исходников подтвердила общий путь Gmail service_client() → load_credentials(): истёкший access token обновляется через сохранённый refresh token, а новая запись сохраняется через keyring в Windows Credential Manager. В GitHub не помещаются токены, OAuth JSON, секрет клиента, адрес аккаунта или частные пути.

Локальная проверка MCP через stdio подтвердила 18 инструментов и совпадение имён и входных схем с локальной фикстурой. Она не читала учётные данные и не обращалась к Google. Живой users.getProfile в этой задаче не повторялся; поиск писем и чтение вложений не выполнялись.

Локальный HOME и публичная ветка — разные состояния: публичный main содержит 17 инструментов на основе своего текущего кода. Успех Gmail API владельца не является самостоятельным доказательством регистрации соответствующих инструментов в любом снимке исходников.

## Состав публичного кода

Основной публичный коммит 846b762753ab01573f51ea8a71b62ac39ffb305f от 16.11.2026 содержит общий MCP-код и компоненты Google Workspace и VTB reports. PR №1 с техническими исходниками объединён.

PR №5 добавил в main отдельный компонент Telegram и инструмент send_telegram_notification. На публичной ветке это 17 инструментов: прежние 16 и отдельный инструмент Telegram. Наличие исходников не подтверждает настройку локального токена или реальную доставку уведомления.

В main также есть базовый компонент bond_search 0.1.0 для чтения переданного снимка правил и ограниченного поиска кандидатов. Полная оценка рисков и торговые операции не реализованы. PR №4 с улучшенной проверкой MOEX, доказательств и статуса Workspace остаётся открытым черновиком; PR №7 также остаётся отдельным открытым черновиком. Их изменения не включены в main.

Компоненты используют общее ядро и одну stdio-точку запуска. Отдельный сервер bond_search и автономные торговые функции не создавались.

## Настройка и безопасность

Инструкции и команды настройки находятся в instructions/ и SETUP.txt. Файлы .env.example — только шаблоны; они не загружаются автоматически.

Секреты, токены, личные конфигурации HOME, финансовые документы, резервные копии и временные данные не должны попадать в этот репозиторий. Подробная процедура авторизации и безопасного профиля Gmail описана в components/google_workspace/docs/GMAIL_OAUTH_SETUP.md.
