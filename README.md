# MSP Bonds MCP (PUBLIC)

Публичный исходный код локального stdio MCP-сервера для технических операций Google Workspace и проверки архива отчётов. Аналитические рекомендации по облигациям и торговые операции в этих компонентах не реализованы.

## Пакеты

- `msp-bonds-mcp` 0.4.0 — точка запуска и общее ядро.
- `msp-bonds-google-workspace` 0.3.1 — Google Drive, Gmail, OAuth и локальное подтверждение записей.
- `msp-bonds-vtb-reports` 0.1.0 — локальный перечень отчётов и проверки форматов.

Компоненты устанавливаются в одну среду Python и работают через один сервер. Проверки подтверждают прежние 16 имён MCP-инструментов и их схемы. 26 автоматических тестов используют синтетические файлы и заглушки; тесты не вызывают Google API.

## Разработка

Начните с `instructions/00_START.txt`. Команды настройки и тестирования находятся в `SETUP.txt`; правила безопасности и контроля изменений — в `instructions/07_SECURITY.txt` и `instructions/08_CHANGE_CONTROL.txt`.

Публичный репозиторий не содержит токены, реальные конфигурации, финансовые документы или локальные пути. Примеры `.env.example` содержат только условные значения и не загружаются автоматически.
