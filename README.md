# MSP Bonds MCP (PUBLIC)

Локальный stdio MCP-сервер для технических операций Google Workspace и проверки архива отчётов. Аналитические рекомендации по облигациям и торговые операции не реализованы.

**В открытом GitHub не публикуются реальные данные портфеля и брокерских документов, секреты, персональные данные или личные настройки HOME.**

Старт проекта: `instructions/00_START.txt`; правила изменения исходников: `instructions/08_CHANGE_CONTROL.txt` и `instructions/11_CHAT_COORDINATION.txt`. Закрытая проектная политика хранится отдельно.

## Проверенное состояние HOME

На HOME проверена одна stdio-точка запуска: ядро `msp-bonds-mcp` 0.4.0, Google Workspace 0.3.1 и ВТБ 0.1.0. Метаданные пакетов совпадают с исходниками. На 15.11.2026 пройдены 56/56 локальных тестов; контракт сохранил прежние 16 MCP-инструментов и их входные схемы.

Локальный компонент ВТБ извлекает текст XLSX и PDF, классифицирует документы по содержимому и ведёт метаданный журнал сверки/импорта. PDF разбираются локально через `pypdf`; OCR не используется. Архивная выборка проверялась только на чтение. Документы, реквизиты и результаты отдельных файлов в GitHub не добавлялись. Поддержка сканированных PDF без текстового слоя не подтверждена.

Gmail, OAuth, живые Google API и облачные операции записи не проверялись и не выполнялись.

## Состав публичного кода

Ветка PR №1 готовит публикацию исходников общего MCP 0.4.0, Google Workspace 0.3.1 и ВТБ 0.1.0. До слияния PR эти исходники не входят в `main`.

Публичный код ВТБ в PR №1 ограничен просмотром файлов локального архива и проверкой признаков формата PDF/XLSX. Он не содержит более свежего HOME-разбора XLSX/PDF, классификатора и метаданного журнала. Эти версии и результаты не следует смешивать.

В актуальном `main` уже есть отдельный `components/bond_search` 0.1.0. Его код умеет проверять переданные снимки таблиц правил и выполнять только первоначальный поиск-кандидатов; полная оценка требований, реальные ценные бумаги и живые сайты не проверялись. Компонент не установлен на HOME и не зарегистрирован в общем MCP-сервере. Он не создаёт отдельный MCP-сервер и не разрешает торговлю. Подробнее: `components/bond_search/docs/README.md`.

Компоненты используют общее ядро и одну stdio-точку запуска. Интеграция Telegram и отправка уведомлений пока не реализованы.

## Настройка и безопасность

Инструкции и команды настройки находятся в `instructions/` и `SETUP.txt`. Файлы `.env.example` — только шаблоны; они не загружаются автоматически.

Секреты, токены, личные конфигурации HOME, финансовые документы, резервные копии и временные данные не должны попадать в этот репозиторий.
