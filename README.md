# MSP Bonds MCP (PUBLIC)

Проект MCP-сервера для анализа портфеля российских корпоративных облигаций на компьютере HOME. Пока на этапе настройки: работоспособность сервера не подтверждена.

**Здесь нет реальных данных портфеля, паролей, токенов и индивидуальных конфигураций.**

Старт для ChatGPT и разработчиков: `instructions/00_START.txt`.
Старт для локального Codex: `AGENTS.md` (далее короткие TXT).
Приватная политика и настройки ведутся отдельно в репозитории `msp-bonds-private`; реальные секреты не коммитить даже туда.

Хранилище данных и контекстных файлов проекта: выделенная папка Google Drive, точные путь/ID необходимо подтверждать перед автоматизацией.
