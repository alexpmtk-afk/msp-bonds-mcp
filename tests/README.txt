[ТЕСТЫ]
Проверки используют синтетические данные, временные файлы и заглушки. Реальные брокерские отчёты, портфельные сведения, токены и закрытые конфигурации запрещены.

В Windows PowerShell полный набор запускается командой `.\scripts\test-all.ps1`. Отдельные пакеты можно проверить командой `python -m unittest discover -s <каталог_тестов> -p 'test_*.py' -v`.
